# 3RING Domain Manager

WordPress plugin from [3RING Studios](https://3ring.com) for managing a company domain portfolio (registrars, DNS, renewals, documents, expiry alerts).

**WordPress.org author:** [@3ring](https://profiles.wordpress.org/3ring/)  
**GitHub:** [80GritPolymath/3ring-domain-manager](https://github.com/80GritPolymath/3ring-domain-manager)

## Layout

| Path | Purpose |
|------|---------|
| `3ring-domain-manager/` | Distributable plugin (WordPress.org SVN / installable package) |

## Install (from this repo)

1. Copy `3ring-domain-manager/` into `wp-content/plugins/`, or zip that folder and upload via **Plugins → Add New**.
2. Activate **3RING Domain Manager**.
3. Open **Domain Manager** in wp-admin.

## WordPress.org distribution

Development happens on GitHub. After [plugin directory](https://wordpress.org/plugins/developers/add/) approval, releases are published via the WordPress.org SVN repository (see [Using Subversion](https://developer.wordpress.org/plugins/wordpress-org/how-to-use-subversion/)). WordPress.org generates the public download zip from SVN tags.
